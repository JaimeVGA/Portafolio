# Portafolio Personal — Cyber Agentic UI

Portafolio web moderno de alto rendimiento con interfaz interactiva inspirada en la arquitectura de **agentes de IA**, estética cyber-editorial y componentes glassmorphism.

## 🚀 Características
- **Hero con simulación de agentes:** Secuencia animada donde agentes virtuales (`LAYOUT`, `TYPE`, `COPY`, `PHOTO`, `UI`) miden y construyen la interfaz en tiempo real, con consola de logs, barra de progreso y botón de reconstrucción.
- **Módulo de foto con sensor interactivo:** Canvas interactivo con respuesta al cursor, coordenadas dinámicas y efectos visuales de radar.
- **Sección Sobre Mí (Bio & Manifiesto):** Ventana estilo terminal de sistema operativo con bio, enfoque de ingeniería y línea de tiempo académica.
- **Sección de Habilidades (Stack Técnico):** Categorizado (Frontend, Backend, IA & Data, DevOps & Tools) con barras de nivel animadas, métricas de experiencia y sin depender de canvas infinitos.
- **Sección de Proyectos:** Tarjetas estilo ventana macOS con badges, tags técnicos, enlaces a GitHub/Demo y modal Lightbox detallado.
- **Sección de Certificados:** Grid de credenciales y reconocimientos con validación directa.
- **Sección de Contacto:** Formulario interactivo, copia de correo al portapapeles y enlaces a perfiles sociales.
- **Diseño Ultra Responsivo:** Adaptado a móviles, tablets y monitores ultrawide con tipografías Google Fonts (*Anton*, *Instrument Serif*, *Inter*, *JetBrains Mono*).
